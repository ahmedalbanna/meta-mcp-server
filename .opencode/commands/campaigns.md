Manage Facebook/Instagram advertising campaigns.

Without arguments: list all campaigns with status, budget, and performance.

With arguments:
- `/campaigns active` — show only active campaigns
- `/campaigns paused` — show only paused campaigns
- `/campaigns pause [ID]` — pause a campaign
- `/campaigns resume [ID]` — resume a campaign
- `/campaigns insights [ID]` — show campaign performance metrics

Use these tools:
- `list_campaigns` — get campaign list
- `get_campaign` — get campaign details
- `update_campaign_status` — change status
- `get_campaign_insights` — get performance data
